Icons

The full icons registry from src/app/icons/icon.definitions.ts. Use <app-icon [icon]="icons.name" />; never paste inline SVG into a template. Click a tile to copy its markup. Missing an icon? Add it to the registry, then run node scripts/sync-foundation-icons.mjs.

Action buttons (icon + label)

The standard for modal footers and toolbars. Icon at 18px, label shown from 769px up, icon-only 44px target on mobile. aria-label and title are required because the label hides.

Desktop
Mobile (≤768px)
  • Order in a footer: secondary/destructive on the left of the group, primary last (right-most).
  • Icon pairs: save → check, close/cancel → close, delete → trash, share → share, copy → copy, add → plus, edit → edit, archive → archive, download → download, busy → loader.
  • Don't mix plain-text buttons and icon buttons in the same footer.
Markup
<button
  type="button"
  class="button button-primary action-button"
  [disabled]="!canCreate()"
  (click)="create()"
  [attr.aria-label]="'checklistFeedback.share.create' | translate"
  [title]="'checklistFeedback.share.create' | translate"
>
  <app-icon [icon]="creating() ? icons.loader : icons.share" />
  <span class="action-label">{{ 'checklistFeedback.share.create' | translate }}</span>
</button>

Icon buttons (toolbar)

Source: .group-toolbar-icon-btn in src/styles/_groups.scss and @mixin icon-button-40. 40px square on desktop, 44px on mobile, 22px icon.

  • Default = outlined brand; --active for a toggled state (with aria-pressed); --filled for the one main toolbar action; --danger sits last with extra start margin.
Markup
<div class="group-header-actions">
  <button type="button" class="group-toolbar-icon-btn" [attr.aria-label]="'files.edit' | translate" [title]="'files.edit' | translate">
    <app-icon [icon]="icons.edit" />
  </button>
  <button type="button" class="group-toolbar-icon-btn group-toolbar-icon-btn--danger" …>
    <app-icon [icon]="icons.trash" />
  </button>
</div>

Floating action button

Source: src/styles/_floating.scss via <app-floating-add-button>. Fixed bottom-right (add) or bottom-left (upload); 50% opacity until hover/focus; hidden while a modal is open.

  • One FAB per corner per page. Lists that sit under a FAB use @include overflow-scroll-y-with-clearance so the last row stays reachable.
